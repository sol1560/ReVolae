CuaRemote 不是远程桌面。你在手机上说要做什么，Mac 上的 agent 自己决定用命令行、AppleScript、快捷指令还是模拟点击去完成，然后把结果发回来。

你能做的事
• 「跑一下 deploy 脚本」「把桌面上的 proposal.pdf 发给张三」——打字或按住说话
• 实时看每一步在做什么，随时取消
• 敏感操作（系统级命令、装软件、涉及支付的应用）会推到手机，Face ID 确认后才继续
• 完整的远程终端和 SSH 客户端，命令按块折叠、复制，能直接问「刚才为什么报错」
• 通过 USB 小配件控制 iPad：对 iPad 来说它就是一个外接键鼠，任何 app 都察觉不到
• 一部手机管多台 Mac / iPad / Android

隐私由你选
• 大脑跑在你的 Mac 上还是云端，由你决定
• 模型：标准云端、零数据保留端点、自带 API key，或完全本地（Ollama / LM Studio）
• 历史、截图、日志、快捷指令逐项决定要不要同步；同步的是端到端密文，服务器解不开
• 手机和 Mac 之间全程端到端加密，服务器只负责转发

开源
核心代码（Mac 端、协议、大脑、预检）以 AGPL-3.0 开源，你可以自建服务器。

需要 macOS 26 或更新版本的 Mac 安装 CuaRemote 桌面端。iPad 控制需要单独的 USB 配件。
